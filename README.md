# Семейный бюджет

Мобильное приложение для учёта личного бюджета с возможностью совместного ведения общего бюджета в группах (семья, соседи по квартире).

Пользователь ведёт свои счета, операции, лимиты, бюджеты и цели, а при желании создаёт группу или вступает в неё. В группе Владелец задаёт структуру учёта, а Участники вносят свои операции.

Данные хранятся на устройстве и шифруются на стороне клиента, поэтому сервер синхронизации не может прочитать содержимое.

Проект создан в 6 семестре (проектирование) и сопровождается в 7 семестре (дисциплина «Программная инженерия», РАНХиГС).
