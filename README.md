# Мобильное приложение для учета бюджета

Проект мобильного приложения для личного учёта денег и совместного бюджета семьи
или другой группы. Приложение должно хранить данные на устройстве, работать
с уже загруженными данными без сети и синхронизировать изменения после подключения.
Финансовые данные шифруются на стороне клиента.

В репозитории находится проектная документация. Само приложение не реализовано.
Работа выполнена по дисциплине «Программная инженерия», РАНХиГС: проектирование
в 6-м семестре и сопровождение документов в 7-м.

## Пользователи

- Пользователь ведёт личные счета, операции, бюджеты и цели.
- Владелец группы управляет общими счетами, составом группы и доступом к данным.
- Участник группы вносит и исправляет свои операции на доступных общих счетах.

Один человек может иметь разные роли в разных группах и вести личный бюджет.

## Основные возможности по проекту

1. Регистрация, вход и восстановление доступа по recovery key.
2. Личные и общие счета, категории и лимиты расходов.
3. Учёт доходов, расходов и переводов между счетами.
4. Бюджеты, цели накопления, регулярные платежи и кредиты.
5. Группы с ролями и настройкой видимости общих данных.
6. Аналитика и уведомления о финансовых и групповых событиях.
7. Локальный учёт без сети и последующая синхронизация.
