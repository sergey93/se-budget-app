# Запрос на изменение CR-1

## Название

Экспорт личных доходов и расходов в CSV.

## Причина

Пользователь хочет разбирать свои расходы в электронной таблице и передавать
данные бухгалтеру без ручного переписывания. Сейчас в требованиях есть просмотр
аналитики, но выгрузка операций не описана.

## Новое требование

Планируемое ФТ-22: Пользователь может выбрать период и сохранить свои личные
доходы и расходы в CSV. Каждая строка содержит дату, тип операции, счёт,
категорию, сумму, валюту и комментарий. Групповые операции и переводы в эту
выгрузку не включаются. Экспорт работает по локально сохранённым данным без сети.

## Что потребуется изменить

| Материал | Изменение |
|---|---|
| Функциональные требования | Добавить ФТ-22 с составом полей и ограничением на личные операции. |
| Архитектура | Добавить экспорт в обязанности модуля аналитики; чтение через слой данных с проверкой владельца. |
| UML классов | Добавить метод получения строк экспорта у Operation. Использовать существующие Account и Category; новая сущность не нужна. |
| Сценарии и последовательность | Описать выбор периода, чтение личных операций, создание файла и сообщение о результате. |
| Тест-кейсы | Проверить отбор по периоду и отсутствие групповых операций и переводов; отдельно проверить пустой период. |
| Руководство пользователя | Добавить инструкцию по выгрузке и предупреждение: сохранённый CSV содержит открытые финансовые данные. |

## Версия и статус

Планируемая версия — 1.2.0: добавляется новая возможность.
Запрос подготовлен для рассмотрения и не реализован. ФТ-22 не добавлено
в действующие требования, экспорт не включён в текущие возможности приложения.
